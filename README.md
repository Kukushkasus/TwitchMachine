# Донат-бот для Twitch-чата (DonationAlerts)

Что делает программа: как только приходит донат через DonationAlerts,
бот сам пишет в чат Twitch сообщение вида:

    💰 Иван задонатил 100 RUB: спасибо за стрим!

Мат и плохие слова в тексте доната автоматически вырезаются на `***`
(и русский, и английский), плюс можно добавить свои слова в файл
`banned_words.txt`.

Ничего устанавливать не нужно — просто `.exe`-файл.

---

## Что понадобится один раз перед первым запуском

### 1. Twitch-токен

Бот будет писать в чат от имени аккаунта, чей токен ты дашь
(в вашем случае — от имени самого стримера).

1. Открой https://twitchtokengenerator.com/
2. Выбери **Bot Chat Token** (или Custom Scope Token со скоупами
   `chat:read` и `chat:edit`)
3. Войди под тем Twitch-аккаунтом, от имени которого бот будет
   писать в чат
4. Скопируй **ACCESS TOKEN** (набор букв и цифр, БЕЗ приставки `oauth:` —
   если она есть, ничего страшного, программа сама её уберёт)

### 2. Приложение DonationAlerts

1. Открой https://www.donationalerts.com/application/clients
2. Создай новое приложение (имя — любое, например "Chat Bot")
3. В поле **Redirect URI** укажи ровно так, без изменений:
   ```
   http://localhost:8942/callback
   ```
4. После создания скопируй **Client ID** и **Client Secret**

## Первый запуск

1. Запусти `donation-bot.exe`
2. Программа задаст несколько вопросов прямо в окне:
   - ник Twitch-канала
   - Twitch OAuth-токен (из шага 1)
   - DonationAlerts Client ID и Client Secret (из шага 2)
   - шаблон сообщения (можно просто нажать Enter — оставить стандартный)
3. Откроется браузер — нужно один раз войти в DonationAlerts и разрешить
   доступ приложению. После этого браузер можно закрыть.
4. Всё, бот запущен и слушает донаты.

Все настройки сохранятся в `config.json` рядом с exe — при следующих
запусках вопросов уже не будет, и повторно логиниться в браузере тоже
не придётся (токен обновляется автоматически).

Если что-то ввёл не так — открой `config.json` в блокноте и поправь,
либо удали его и запусти exe заново.

**Во время стрима просто держи это окно открытым** (можно свернуть).
Чтобы остановить бота — закрой окно.

## Фильтр слов

- Русский и английский мат вырезается автоматически, ничего настраивать
  не нужно (учитываются и попытки обхода вроде "бл9ть", "х@й" и т.п.)
- Файл `banned_words.txt` — свой список дополнительных слов/фраз,
  по одному на строку. Например, туда можно добавить конкретные слова,
  за которые банят на Twitch, или ссылки на сторонние сервисы, которые
  не хочется видеть в чате. Строки с `#` в начале — это комментарии,
  их бот игнорирует.
- Донат никогда не блокируется целиком — сумма и ник доносятся всегда,
  вырезаются только конкретные плохие слова в тексте.

## Шаблон сообщения

В `config.json` есть поле `messageTemplate`. Доступные плейсхолдеры:

- `{user}` — ник донатера
- `{amount}` — сумма
- `{currency}` — валюта
- `{message}` — текст доната (уже отфильтрованный)

Например:
```
"messageTemplate": "🎉 Новый донат от {user} — {amount} {currency}! Сообщение: {message}"
```

## Частые проблемы

- **Бот не пишет в чат** — скорее всего, протух/неверный Twitch-токен.
  Получи новый на twitchtokengenerator.com, впиши в `config.json` в поле
  `twitchOAuthToken` и перезапусти.
- **Ошибка авторизации DonationAlerts** — проверь, что Redirect URI в
  приложении на donationalerts.com указан ровно как
  `http://localhost:8942/callback`, без слэша на конце и без "https".
- **Windows Defender/антивирус ругается на exe** — это стандартная
  ложная тревога для программ, собранных через `pkg` (упаковщик Node.js
  в exe), она часто помечает подобные файлы как подозрительные просто
  потому что они самораспаковывающиеся. Можно добавить файл в
  исключения.

## Сборка из исходников
(Готовая папка в релизах)
Нужен установленный Node.js.

```bash
npm install
npm run build
```

Готовый `donation-bot.exe` появится в папке `build/`.

Отдельно можно собрать только бандл (для разработки/отладки):

```bash
npm run bundle   # соберёт dist/bundle.js
npm start        # запустит src/index.js напрямую, без сборки в exe
```

`config.json` и `tokens.json` создаются автоматически при первом запуске
и в репозиторий не попадают (см. `.gitignore`) — там личные токены.
Шаблон списка слов лежит в `banned_words.example.txt`; при первом
запуске программа сама создаст рабочий `banned_words.txt` рядом с exe.
